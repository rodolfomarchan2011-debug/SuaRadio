# Prompts IA para vinhetas / spots da SuaRadio

Use no ElevenLabs, Suno, CapCut, Clipchamp ou ChatGPT + TTS.

## 1. Vinheta de abertura
```
Voz feminina animada, português Brasil, 8 segundos:
"Bem-vindo à Sua Rádio! A sua vibe, do seu jeito!"
Fundo: pop leve, sem cobrir a voz.
```

## 2. Spot genérico de intervalo
```
Voz masculina grave, locutor de rádio:
"Você está ouvindo a SuaRadio. Fique ligado, já já tem mais música!"
Duração: 10 segundos.
```

## 3. Hora certa
```
Gere áudio: "Agora são [HORA] horas na SuaRadio" com voz natural.
```

## 4. Como gerar música de fundo livre
- Suno / Udio: prompt `lofi chill 90 bpm, no vocals, royalty free feel`
- Sempre salve como MP3 e coloque na pasta `minhas-musicas/`

## Dica
Salve os MP3 gerados como:
- `vinheta-abertura.mp3`
- `spot-intervalo.mp3`
- `minha-musica-01.mp3`
Depois é só selecionar no app.
