# 📻 SuaRadio — Uso Pessoal

App simples para você organizar sua rádio pessoal:
YouTube (player oficial) + suas músicas/MP3 intercalando no automático.

## Como usar (2 min)

1. Abra o arquivo `index.html` no Chrome (duplo clique).
2. Cole links do YouTube na caixa 1 → `Carregar YouTube`.
3. Em `Minhas músicas` clique e selecione seus MP3 (vinhetas, spots, suas gravações).
4. Configure: `a cada N vídeos` ex: 2. Ou `a cada X minutos` ex: 15 (0 = desligado).
5. Aperte `▶️ Iniciar rádio`.

Ele toca YouTube, pausa sozinho, toca seu MP3, e volta pro YouTube.

## Regras para continuar legal

- Uso **pessoal** apenas. Não use em loja/empresa.
- Não baixe áudio do YouTube. O app usa o player oficial embedado, por isso é permitido.
- Seus MP3 precisam ser seus ou livres que você tem direito.
